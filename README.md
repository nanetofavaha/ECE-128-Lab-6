# ECE-128-Lab-6: Finite State Machines

## Description

This lab focuses on designing and simulating a switch debouncer, a Moore sequence detector (1100), and a Mealy overlapping sequence detector (1101) using Verilog. The designs were tested using behavioral simulations in Vivado, with the switch debouncer intended for implementation on the Basys 3 FPGA board

## Simulation

1. Open the project in Vivado
2. Add the Verilog source code and testbenches
3. Run the behavioral simulations
4. Use the waveforms to verify the outputs for each design

## FPGA Implementation

1. Add the XDC constraints file to the project
2. Assign the push button, clock, and LED pins for the switch debouncer
3. Run synthesis and implementation
4. Generate the bitstream
5. Connect and program the Basys 3 FPGA board
6. Press the push button and observe the corresponding LED output
